# 🪵 TimberCalc
 
Dimensionamento de peças de madeira à tração e à compressão paralela às fibras, com memória de cálculo passo a passo.
 
## Sobre o projeto
 
O **TimberCalc** é uma ferramenta acadêmica que automatiza o dimensionamento de peças estruturais de madeira de seção retangular submetidas a esforço normal (tração ou compressão paralela às fibras) no Estado Limite Último (ELU).
 
Ele permite escolher entre os critérios da **ABNT NBR 7190-1:2022** e da **ABNT NBR 7190:1997**, apresenta cada etapa do cálculo (propriedades, combinações, verificações) e indica automaticamente se a peça atende ou não aos requisitos de segurança.
 
## Como usar
 
**Opção 1: online (recomendado).** Acesse a página publicada no GitHub Pages:
 
https://raquelmarcios.github.io/timbercalc/
 
**Opção 2: offline.** Baixe o arquivo `index.html` e abra-o com duplo clique em qualquer navegador (Chrome, Edge, Firefox, Brave…).
 
### Passo a passo
 
1. Escolha o critério normativo e o tipo de esforço.
2. Selecione os dados de um dos grupos do enunciado ou preencha os parâmetros manualmente.
3. Clique em **Calcular**.
4. Confira a memória de cálculo e o resultado final.
5. Se quiser, salve a memória de cálculo em PDF.
